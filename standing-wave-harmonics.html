About This Instrument

Why These Four Instruments?

Each one confines a wave with a different geometry, and that geometry alone determines which harmonics can exist. A string fixed at both ends and a pipe open at both ends behave the same way mathematically: both support every integer harmonic. A pipe closed at one end only sustains odd harmonics, because the closed end must be a node while the open end must be an antinode.

The saxophone is the exception that proves the rule. It's closed at the reed end like a clarinet, but its conical bore changes the boundary behavior enough that it acoustically behaves like an open-open pipe: every integer harmonic, not just odd ones.

On the Guitar String

This models a generic fixed-fixed string, the same physics whether it's an acoustic or electric guitar, a bass, or a piano string; nothing here models a pickup, a soundboard, or an amplifier, only the string's own vibration. The defaults (0.65 m scale length, about 75 N tension, 1.15 g/m linear density) are chosen to give a real, in-tune G3 (196.0 Hz) on open string, matching a typical guitar's 3rd (G) string, comfortably within the treble staff rather than requiring many ledger lines.
